# Contributing

## Before submitting changes

1. Keep changes focused and easy to review.
2. Do not commit `setting_wa.ini` or real personal phone numbers.
3. Run:
   - `python -m py_compile src/whatsapp_link_generator.py`
   - `pytest`
4. Update `README.md` when user-visible behavior changes.

## Pull requests

Please describe:

- What changed
- Why it changed
- How it was tested
- Any compatibility considerations
